# 2026-11-17

## interstellar：卡冈图雅（黑洞）着色器重写 —— 消掉「拼接感 / 线条切割」

用户反馈：黑洞像被一条线从中间切开、有拼接感。定位到的真因有三个，全部修掉了。

### 1. 零厚度盘 = 一条线 + 缝线虚线（主因）
旧实现对盘做「平面单点求交」：`ph*vh<0` 时线性求交、取一点着色。视线几乎贴着盘面（这个机位就是掠射），
浮点上 `ph*vh` 会丢精度 → 部分像素漏采样 → 盘上出现一排排黑点/虚线（像缝线的针脚）；
同时几何零厚度 → 侧看就是一条 2px 的直线，把阴影切成两半。

**改法**：把盘当成有厚度的气壳，沿光线做体积累积：
- `hz = uDiskH * (0.055 + 0.030*rr)`（外张薄盘，uDiskH 默认 1.35）
- 垂直分布 `exp(-1.8 t²) + 0.17*exp(-0.22 t²)`（窄核 + 宽晕，盘缘才不像贴上去的板子）
- `q = dens * dt / hz * 0.46`，`acc += shade*q*(1-opa)`，`opa += q`
- `if (opa > 0.985) break;` —— 光学厚就停，既省步数又避免过度累积

### 2. 步数预算边界 = 一条圆弧接缝
掠射光线（视线几乎在盘面内）在盘里走很久，细步长会把 200 步耗光 →
没逃出去的光线用「当前位置的 v」采样星空 = 随机星点 → 把预算边界描成一条大圆弧（半径 ~2.6 倍阴影）。

**改法**：步长按「一步跨过几个 hz」定，而不是按绝对长度：
```
float svh = abs(dot(v, uDiskN)) / length(v);        // 视线与盘面夹角正弦
dt = min(dt, hz * mix(0.92, 0.36, dn) / max(svh, 0.035));
```
迎头穿盘（svh≈1）小步、掠射（svh≈0.035）大步，两者都拿到平滑垂直分布。
另外步数耗尽时**不再用随机 v**，直接退回解析偏折方向（`escaped=false → skyDir`）。

### 3. 追迹区边界 = 又一条接缝（星点被拉成白痕）
`mix(col, lensed, w)` 的边界处，追迹结果与裸星空对不上（这个尺度上偏折角还有 0.1~0.3 rad），
边界上星星被拉成一条条白色细划痕，看着像"刀痕"。

**改法**：整屏背景都用同一条**解析弱场偏折**曲线采样（`skyDir()`：α ≈ 2rs/b 朝黑洞弯），
追迹内部再按 w 从解析方向过渡到测地线方向。边界两侧方向几乎重合 → 没有接缝。
- 权重 `w = smoothstep(lensA, lensA*0.80, ang)`：一定要在盘外（8~9 rs）就收到 1，
  否则盘的 5.2~6.9 rs 外缘会被这个过渡压暗，浮出一圈亮环。
- 追迹区里干脆不画背景星（`bg*(1-opa)*(1-w)`）：被透镜拉长的星点会变成一道道白痕，
  而电影里这个曝光下背景本来就基本是纯黑。

### 4. 光子环 = 一圈虚线 → 只在阴影边缘做 4× 旋转超采样
`shadowA = 2.9*uRs/dBH`，只在 `ang ∈ [0.80, 1.40]*shadowA` 这一圈里补 3 个旋转偏移样本
（`uPx` = 每像素弧度，resize 时按 fov + drawingBufferHeight 更新）。做宽了帧率直接砍半。

### 性能（1440×900，AMD 集显，headless chrome）
- 原始版本 32.5 fps；第一轮体积化 + 超采样 → 14.4 fps；final 29.5 fps。
- 关键一招：远场步长上限 `clamp(0.085*r, 0.032, 2.2)`（原来 0.85），
  进场段步数砍半；追迹区 `lensA` 从 14 → 11.5 rs。

### 其他
- 盘纹理用 `atan` 取角后**只经 cos/sin 使用**，天然绕轴闭合，不会出现 0/2π 接缝。
- RK2 中点法积分（原来是欧拉）→ 光子环更圆。
- 新增 URL 参数 `?diskh=`（盘厚度系数），`?bhsteps=` / `?bh=0` 仍在。
