## 渲染方案（js/showcase7/main.js + css/mk7.css + mk7.html）
三通道：① MeshNormalMaterial 法线通道 ② MeshStandardMaterial 颜色+深度通道（RT 挂 DepthTexture）③ 全屏合成 pass 做边缘检测。
- 反照率：`textureLod(map, vMapUv, 5.0)` 降 mip → 干净色块（onBeforeCompile 替换 `<map_fragment>`）
- 法线：normalScale 0.45；再按 UV 空间对 normalMap 求差分注入刻线（替换 `<normal_fragment_maps>`）
- 粗糙度：替换 `<roughnessmap_fragment>` 为 `mix(0.38, 0.21, smoothstep(0.08,0.55, 基色亮度))`（金亮红哑）；注意 three 的该 chunk 自带 `float roughnessFactor = roughness;`，整条替换不要重复声明
- 合成：法线夹角 + 深度二阶差分 + 亮度 Sobel + 局部对比，暗线/亮线两模式
- **坑**：GLSL ES 不支持函数嵌套定义（`float lum()` 放 main 里会编译失败，表现为整屏纯紫 = normalRT 清屏色）。函数必须放文件作用域。
- **坑**：合成 pass 不能再 `#include <tonemapping_fragment>`（材质阶段已 tone map，重复应用会整体变暗），只需 `colorspace_fragment`。
- **坑**：接影面/接触阴影必须在法线通道里隐藏，否则画出矩形边缘。
- **坑**：真实平行光阴影在 ShadowMaterial 大平面上会出现阴影相机视锥边界条带 → 改用 CanvasTexture 径向渐变接触阴影（1.9×1.9 平面，opacity 0.75），同时省掉一整趟 shadow pass。
- 真实阴影/自阴影也验证过：headless 下会拖出长条影且边界明显，产品图风格不如接触阴影干净。

## 追加：仅线条开关 + 表面亮度调节（已推送 036868a）
- 合成 shader 新增 `uSurface`（0..1）：`col = mix(vec3(lum), col, uSurface) * mix(0.16, 1.0, uSurface)` —— 一个量同时做「去饱和 + 压暗」，0 即纯线稿底色。
- 暗背景下暗线会消失，故 `lineLight = clamp(uLight + 1.0 - smoothstep(0.0, 0.55, uSurface), 0, 1)`，表面越暗线条自动转亮色；线条 alpha 也用 lineLight 插值。

## 追加：线条颜色 / 流光 / 拆解合并（本地提交 b41940e，未推送）
### 线条颜色 + 流光（合成 pass）
- `uLineColor`（THREE.Color，默认 #dbedff）+ `uTime` + `uFlow`（0/0.9）。取色器 `input[type=color]` 直接 `uniform.value.set(hex)`（ColorManagement 自动转线性）。
- 流光做在合成 shader 里而不是材质里：`fy = fract(vUv.y*1.35 - uTime*0.22)`，三角脉冲带；`lineCol = mix(lineCol, uLineColor*(1.18+0.95*pulse), pulse)`，alpha×(1+0.3pulse)。好处：纯线稿 / 拆解 / 任意线条色都有效，且不需要额外 pass。
- 峰值别给太高：1.9 倍以上会把红色线条推成大片白斑（过曝）。
### 拆解 / 合并（js/showcase7/segment.js）
- armor2.glb 是**单块蒙皮网格**：节点 matrixWorld（scale 0.085）× 几何包围盒 完全对不上渲染位置（bindMatrix 是单位阵，静止姿态由骨骼决定）。`Box3.setFromObject` 给出的 1.98m 也和 nodeMW×geoBBox(0.42m) 矛盾。
- 正解：用 skinIndex/skinWeight 手动蒙皮 —— `v = pos → bindMatrix → Σ(w_i · boneMW_i · boneInverse_i) → bindMatrixInverse → nodeMW`；法线同理取 mat3 链再 normalize。烘焙后自己算 bbox 归一化（高 1.95、贴地、居中），彻底不依赖任何节点矩阵。
- 切分沿用 index 页的阈值思路，但**手/前臂不能单独切**：这份模型腕部包了一块长条护板，任何高度横切都会把它撕成薄片 → 定为 7 模块（helmet/chest/back/armL/R/legL/R）。
- pivot.position = center + offset·H·t，子网格顶点已减 center（旋转/位移都绕模块中心）；位移恒基于 base，反复拆装无累积误差。
- **拆解构图**：零件上移会飞出取景框 → 拆解时相机后拉 1.45×、视点抬到 0.64H（`splitTargetY()`），用 zoomAnim 同时补间距离与 target.y；resetView 按 split 状态套用同一套参数。
- 快捷键：E 拆卸/合并、G 流光；按钮「拆卸/合并」文字随状态切换。
- 验证：1440×900@2x 与 390×844 全组合截图通过，7 模块边界干净，FPS 75–90，三页回归 0 报错。
