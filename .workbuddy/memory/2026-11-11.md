## 反应堆辉光：呼吸环 → 自内向外扩散的能量波纹（commit 0fc73ba）

- 位置：`js/showcase7/main.js` 合成 pass 的 shader（edgeMat），反应堆核心段。
- 旧实现：`ringR = 1.32 + 0.30*sin(t)` 的呼吸环，只有一张环在固定半径上下浮动，观感弱。
- 新实现：
  - `shock`：`ph = fract(uTime*0.22)`（4.5s 一道），`d = r - ph*maxR`（maxR=4.2），
    前缘 `exp(-d*24)` 极锐、内侧 `exp(-d*6)` 缓收，再乘 `pow(1-ph,1.25)` 随扩散衰减。
  - `rings`：`pow(0.5+0.5*sin(r*5.2 - uTime*4.0), 14.0) * exp(-r*0.5)` 同心细纹随之前行。
  - `rip = max(shock, rings*0.9) * 2.3`。
  - **遮挡**：波纹不复用光核的 `uCoreWall=1.1`（会把波切死在晕边），
    单独 `occlWide = smoothstep(R*3.6, R*2.2, along)`，胸甲/肩甲能过，手臂仍被挡。
  - **沿纹路**：`trace = clamp(edge*1.7)`（edge = 法线/深度/亮度三路边缘），
    平板只加 0.09 强度淡青雾，刻线加 1.9；
    且**必须用 mix 替换线条颜色**（`ripTint = mix(coreCol*1.05, white, 0.28)`），
    因为线条本身已近纯白，加色的 additive 会直接溢出成白 —— 这一步是效果可见的关键。
- 调参旋钮（都在 shader 里，非 CONFIG）：`maxR`、`ph1` 速率、`rings` 频率/幂次、
  `rip` 振幅 2.3、平板系数 0.09、`trace` 系数 1.9/2.2。
- 验证：mk7.html 反浩克 embed / jarvis-console 双展位 / ironman-hud / MK7 模型，0 pageerror。

## HUD 恢复反应堆高亮：静态辐射（commit 1e7df29）

- 需求：HUD 页要有胸口高亮，但**不要圆环波纹**，保留「亮线从内往外辐射淡化」。
- `ironman-hud.html` 的 `#armor-frame`：`corefx=0` → `corefx=1&corerip=0&corerad=1`。
- 新增 `CONFIG.coreRad` → uniform `uCoreRad`，**默认 0**（不传的页面行为完全不变）。
- 静态辐射实现（shader 内，紧跟在光核之后）：
  - `radA = kw * uCoreGain * uCoreRad * beat`，`beat` 只让明暗呼吸，**不动半径 → 不会变成环**。
  - `radFade = exp(-max(r-0.55,0)*0.58)`，光斑边缘起算向外衰减（0.58 越陡内外反差越明显）。
  - `radTint = mix(white 0.96/1/1, coreCol*1.05, smoothstep(0.5,3.0,r))` —— 内白热外偏青。
  - 刻线：`lineW = clamp(trace*radFade*1.25, 0, .95)*radA`，先 `mix` 到 radTint 再 `+= 0.45` 加色。
  - 平板底光 `0.30 * radA * (0.30+0.70*trace)`：**必须有这一层**，否则亮线模式下线条已近纯白，
    只换色相看不出任何梯度（同波纹那次踩过的坑）。
  - 遮挡复用波纹的 `occlWide`（3.6R），胸甲起伏能过、手臂仍挡住。
- 验证：HUD 整页 + 特写（deviceScaleFactor 3）无环、胸口内亮外暗；mk7 反浩克 / console
  未受影响（coreRad 默认 0）；4 处 0 pageerror。
- 调参旋钮：`corerad`（0~1 强度）、`radFade` 的 0.58（衰减速度）、底光 0.30。

## 控制台双展位：波纹收窄（commit cbffc12）

- 需求：console 两个战甲保留反应堆高亮，但铺满胸甲的一圈圈波纹不好看，收小或去掉。
- 新增 `CONFIG.ripMax` → uniform `uRipMax`，URL `?ripmax=`（**默认 4.2 = 原行为**，mk7 独立页未受影响）。
- 两个关键补偿，否则收窄会变形：
  - **相位速率反比**：`ph1 = fract(uTime*0.22*(4.2/maxR))` —— 半径缩小、周期同步变短，
    波前推进**速度**保持不变；不做这个补偿，窄范围里会变成「慢慢爬出一点点」。
  - **细纹按半径淡出**：`ringsK = clamp((maxR-2.2)/1.4,0,1)` —— maxR ≤ 2.2 时完全关掉
    同心细纹，只留主冲击波那一道，否则 sin 周期挤在一起就是一堆乱圈（正是用户嫌弃的点）。
- `jarvis-console.html` 两个 iframe：`corefx=1&corerad=0.5&ripmax=2.2&corerip=0.85`。
- 验证：console 整页 + 3× 特写（反浩克 / MK7 正面），光核清晰、胸口线条轻微由内向外渐隐、
