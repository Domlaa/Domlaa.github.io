## interstellar 改版：环面平躺 + 同轴自旋对接（s3.jpg 之后）

用户给了第三张剧照 `img/interstellar/s3.jpg`，明确要求：**两台飞行器都保持正常姿态 → 以同样角速度绕各自竖直中心轴在水平面内自转 → 把二者的圆心对齐 → 看起来绝对静止后完成对接**。前一版「机背贴环侧轴向面」被判为"对接错位置"。

- **新的世界约定**：`ringPivot` 绕 +Y 转（环面水平）；原始「环轴 = X」的模型塞进 `ringBody`（`rotation.z = π/2`），所以环Pivot 的局部系就是「+Y 向上」的正常坐标系，程序化平台直接按 Y 轴放，不用再做坐标换算。
- **对接位改到环心**：模型实测轮毂顶端（沿 -X 打射线）在 x≈6.42~6.55 处有一小块 r<1 的端面，往外 r≥1.2 就掉到 2.3（十字臂）。所以做了一块程序化中央平台（`padR 6.8`、深色甲板 `#3d4751`、`dockY 6.78` 的落座面、发光环、4 夹爪、12 边灯、4 根斜撑到十字臂），机腹压在上面。
- **落座点用机腹**：登陆艇保持正常姿态（机腹 -Y），`findVentral()` 取最低 6% 顶点重心 → rig 局部 `(0.01, -2.16, -7.68)`，平区 7.2×10.6。`dockLocal.pos = port - quat·belly`。
- **动作编排全在世界系**：泊位是世界固定点（默认 `x=-27, z=21, height=13`），所以分离后登陆艇是**原地绕自己竖轴自转**（yaw = spinPhase + dockYaw - lag）。横向滑回（smoothstep 0.62→1）→ 竖直降落（0.06→0.68）→ 姿态完全摆正（空中倾角只在 0.55→1 存在）。因为落座点在环轴上，最后一段是纯竖直下降，相对环「绝对静止」。
- **遥测**：DORSAL→ATTITUDE（机腹法线 vs 落座面法线），OFFSET 改成横向偏差（落座显示 ALIGNED），新增 **REL SPIN**（机头偏航角速度 - 环自转，同速时显示 SYNC）。
- **踩坑**：`InstancedMesh` 的 `type` 仍是 'Mesh'，判实例要用 `o.isInstancedMesh`；`setFromObject` 会把 InstancedMesh 的全部实例算进 bbox。
- **踩坑**：轮毂端面只有 r≈0.9，没法直接落座，必须程序化补平台，否则像扎在针尖上。
- **踩坑**：绕 Z 转 90° 不能直接改模型的 `rotation`（`normalize()` 已经把 position 设成 -bboxCenter，绕自身原点转会跑偏），要用外层 group。
- **取景**：VIEW_DIR ≈ (0.6,0.64,0.7)（仰角约 35°），构图中心按登陆艇位置偏 22%，距离按「环半径 / 登陆艇-构图中心距离 / 高度」三者取大。
- 验证：1280×820、812×375、390×844、320×568 无 pageerror/requestfailed；分离→保持→对接→夹爪锁定全通；SPIN 关到 0.000 再开回 0.160 正常。

## 对接微偏修正（用户反馈：毂柱圆柱没对齐 lander 顶部对接端口）

- **根因**：锚点用的是机腹板面最低 6% 顶点重心（rig 局部 z=-7.68），而实际的圆形舱口围栏在 (0, -8.459)——偏了约 0.78（≈0.83 m）；垂直方向毂柱下端口面（y=-7.409）与围栏贴面（-7.659）之间还悬空 0.25。
- **修复（js/interstellar/main.js）**：新增 `findHatchPort()`（RANSAC 三点定圆 + 几何距离迭代精修，自动从顶点找出舱口围栏圆环）与 `measureHubBottom()`（毂柱端口面实测），boot 时把锚点从板面重心修正到舱口圆心、并按「端口面坐上围栏顶（咬合 0.02）」反推 dockY（-7.48 → -7.21，全自动，无需手调）。`?docky=`/`?hatchz=` 手动给值时跳过对应自动实测。
- **验证**：舱口圆心落环轴上（latOff=0）、围栏贴面与毂柱端口面 FLUSH、分离→再对接全流程遥测 RANGE 0.0/ALIGNED/SYNC，无 pageerror。
- **踩坑**：① rig 局部系还是未翻转姿态，围栏在板面「上方」0.10~0.26（倒扣后才是沉入舱口）；② Kasa 代数圆拟合在厚环带上会退化成过原点的大圆解（r=|cz|），必须用几何距离迭代；③ band 顶点数组是 [x,y,z]，RANSAC 内点统计时解构成 [x,,z] 会把 y 当 z——静默返回 0 内点。
